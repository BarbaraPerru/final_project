# Final Project

## Project Name
Final Project

## Description
This project is an Emotion Detection web application developed using Python, Flask, and the Watson NLP Emotion Predict service.

The application analyzes a text provided by the user and returns emotion scores for anger, disgust, fear, joy, and sadness. It also identifies the dominant emotion.

## Features
- Emotion detection from text input
- Detection of anger, disgust, fear, joy, and sadness
- Identification of the dominant emotion
- Error handling for blank input
- Unit testing
- Web interface using Flask

## Usage
The application can be started by running:

python3 server.py

The web application runs on port 5000.
